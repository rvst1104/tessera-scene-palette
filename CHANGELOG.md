# Changelog

## 0.2.0

- Fix installation on standard Tessera by removing unsupported optional inputs and custom core APIs.
- Show the scene buttons together inside a 2×2 or larger tile, using standard filtered tile taps.
- Keep all six scene fields empty by default; enter scene entity IDs and names in tile options without firmware rebuilds.
- Remove the prototype popup, per-scene icon options and compatibility patch requirement.

## 0.1.0

- Initial prototype; required a modified Tessera core and was not compatible with the standard Screen Manager.
